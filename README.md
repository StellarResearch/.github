# FLATLINED — Organization Default Files & Health Repository

This repository contains organization-wide community health defaults, profile documentation, and templates for the [FLATLINED](https://github.com/FLATLINEDSTAR) organization.

## Contents

- `profile/README.md`: Rendered on the [FLATLINEDSTAR organization profile](https://github.com/FLATLINEDSTAR).
- `CODE_OF_CONDUCT.md`: Contributor Covenant v2.1 code of conduct applied organization-wide.
- `SECURITY.md`: Organization-level security and responsible disclosure policy.
- `CONTRIBUTING.md`: General open-source contribution guidelines.

## Governing Principles

Repositories under this organization inherit these defaults unless explicitly overridden by a repository-specific file.
